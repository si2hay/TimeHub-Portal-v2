## 📖 О проекте

Это переписанная с нуля версия моего старого проекта. 
Сайт работает как в обычном браузере (с адаптивом под ПК и мобилки), так и в виде Telegram Mini App. Написан на Vite без использования тяжелых фреймворков (Vanilla JS), данные хранятся в Supabase.

### Основные фичи

- 📅 **Умное расписание** — база разбита по неделям (чет/нечет) и дням. На ПК выглядит как удобная двухколоночная сетка. 
- 🧠 **Умный выбор дня** — если сегодня выходной или пары уже закончились, портал автоматически откроет расписание на следующий учебный день (с учетом перехода на новую неделю). Тебе не нужно листать вручную.
- 🔄 **Свайпы** — дни листаются свайпами (пальцем или мышкой) с каскадной анимацией карточек.
- ⏱ **Умный таймер** — учитывает перемены (5/30/35 минут) и разные звонки для 1 и 2+ курсов. Если пары закончились, ищет ближайшую в будущем. Есть полноэкранный режим и кнопка «Ближайший».
- 🔔 **Замены** — староста или админ ставит замены на конкретную дату. Есть поддержка кастомного времени и красная подсветка изменений.
- 🎓 **Консультации** — админ назначает время консультаций, студенты видят их в профиле (с приятной анимацией загрузки).
- 🔥 **Стрик (Огонёк)** — счетчик дней подряд, когда ты заходил на сайт.
- 🎨 **Кастомизация** — можно менять тему (Матовое стекло/Классика), цвета, шрифт, ставить обои, включать частицы. Есть встроенный калькулятор оценок (с читерской кнопкой для математички).
- 🌊 **Жидкая кнопка выхода** — при долгом зажатии кнопка «Выйти» заполняется анимированной жидкостью.
- 🌤 **Погода** — загружается без VPN через прокси `cors.dev`.
- 🛠 **DANGER ZONE** — панель для админов, чтобы подкрутить время/дату для тестов.
- 🔍 **Умный поиск** — ищет с опечатками (расстояние Левенштейна) и игнорирует лишние символы.

## 🚀 Как запустить локально

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/si2hay/TimeHub-Portal-v2.git
   cd TimeHub-Portal-v2
   ```

2. Установи зависимости:
   ```bash
   npm install
   ```

3. Создай `.env` файл в корне и добавь ключи из Supabase (Project Settings -> API):
   ```env
   VITE_SUPABASE_URL=твой_url
   VITE_SUPABASE_ANON_KEY=твой_anon_ключ
   ```

4. Запусти dev-сервер:
   ```bash
   npm run dev
   ```
   Сайт будет доступен на `http://localhost:3000`.

5. Сборка для продакшена:
   ```bash
   npm run build
   ```

## 🗄️ База данных

В проекте 4 таблицы: `profiles`, `schedules`, `substitutions`, `consultations`. 
Везде включен RLS (Row Level Security). Права настроены так:
- Смотреть могут все авторизованные пользователи.
- Редактировать расписание и замены: `admin`, `sap` и `starosta` (только для своей группы).
- Управлять пользователями и консультациями: только `admin` и `sap`.

## 🌐 Деплой

Настроен GitHub Actions. При каждом пуше в `main`:
1. Запускается `npm run build`.
2. Секреты подтягиваются из настроек репозитория.
3. Папка `dist` публикуется на GitHub Pages.

Для работы нужно добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в **Settings -> Secrets and variables -> Actions**.
