## 🛑 ПРАВИЛО №2: ОТВЕТ ДОЛЖЕН БЫТЬ ПОЛНЫМ

- **ЗАПРЕЩЕНО** давать куски кода типа `// ... тут твой старый код ...` или `<!-- остальное без изменений -->`.
- Если меняешь файл — пишешь его **ЦЕЛИКОМ**, от `/** @file ... */` до последней скобки.
- **Обязательно** указывай полный путь к файлу перед блоком кода (например, `### src/features/timer.logic.js`).
- **В каждом файле должен быть заголовок** `@file` и `@description` (для JS) или `/** @file */` (для CSS).
- Комментарии в коде — только на русском языке.

## 🛑 ПРАВИЛО №3: АРХИТЕКТУРА И МОДУЛЬНОСТЬ

- **`src/api/`** — только запросы к Supabase и внешним API.
- **`src/features/`** — только чистая логика и математика (без DOM и запросов к БД).
- **`src/ui/`** — только создание HTML-элементов и обновление DOM.
- **`src/pages/`** — «дирижеры». Связывают API, Features и UI.
- **`src/constants/`** — статичные данные (звонки, группы, словарь).
- **`styles/`** — разбиты на `base`, `layout`, `components`, `themes`. В `main.css` только `@import`.
- **Один файл = одна задача.** Не пихай всё в один файл. Если логика разрастается — выноси в отдельный модуль.

## 1. Обзор проекта

**TimeHub-Portal v2** — учебный портал для студента. Написан на Vite + Supabase, работает как обычный сайт (с адаптивом под ПК и мобилки) и как **Telegram Mini App**.

### 1.1. Функционал
- **Адаптивность (ПК)**: На экранах `> 900px` включается двухколоночная верстка. Слева — липкая (sticky) панель с погодой и таймером (380px). Справа — широкое расписание.
- **Плавные переходы (SPA-like)**: При переходе между HTML-страницами появляется темная шторка с лоадером, скрывающая белую вспышку браузера.
- **Умный выбор дня**: Если сегодня выходной (Сб/Вс) или пары уже закончились (например, в пятницу вечером), портал автоматически открывает расписание на **следующий учебный день** (с учетом перехода на новую неделю).
- **MPA**: `index.html` (вход/регистрация), `pages/app.html` (главная), `pages/admin.html` (админка).
- **Off-canvas меню**: открывается по клику на логотип. Внутри профиля есть аккордеоны для Справочника (Калькулятор, Библиотеки, Консультации).
- **Авторизация**: Email через Supabase. Роли: `admin`, `sap`, `starosta`, `student`.
- **Свайпы дней**: переключение Пн-Пт по кругу свайпом. Каскадная анимация карточек.
- **Умный таймер**: учитывает перемены и звонки 1/2+ курса. Если пары прошли — ищет следующую. Есть **полноэкранный режим** и кнопка **«Ближайший»** (сбрасывает на актуальный учебный день).
- **Календарь в шапке**: клик по дате открывает кастомный календарь с номерами учебных недель. Выходные дни (Сб, Вс) заблокированы для выбора. При загрузке страницы календарь автоматически синхронизируется с умным выбором дня.
- **Замены**: админ ставит на конкретную дату. Автоочистка замен старше 15 дней.
- **Консультации**: админ назначает время. Студенты видят их в профиле (с скелетонами при загрузке).
- **Полное расписание**: модалка в профиле с расписанием на 2 недели вперед.
- **Стрик (Огонёк)**: счетчик дней подряд. Поповер в шапке.
- **Кастомизация**: темы, цвета, шрифты, обои, частицы, градиент. Включает **кастомный калькулятор оценок** (с кнопкой «22222»).
- **Безопасные действия**: Кнопки «Выйти», «Сбросить настройки» и «Удалить фон» требуют удержания (3 секунды) с эффектом заполнения жидкостью, чтобы предотвратить случайное нажатие.
- **Скелетоны и пустые состояния**: при загрузке мерцают заглушки. Если пар нет — показывается SVG-чашка кофе.
- **Погода**: загружается через `cors.dev` (обход CORS и блокировок РФ без VPN).

### 1.2. Стек
- Vite 6
- Vanilla JS (ES6 Modules)
- Чистый CSS
- Supabase (PostgreSQL, Auth, RLS)
- GitHub Pages (через Actions)
- Telegram WebApp API

### 1.3. `.env` (не коммитится)
```env

```

## 3. База данных

4 таблицы с RLS:

1. **`profiles`**: `id`, `email`, `role`, `group_name`, `settings` (jsonb).
2. **`schedules`**: `id`, `group_name`, `week_num`, `day_num`, `pair_num`, `subject`, `room`, `teacher`, `custom_start`, `custom_end`.
3. **`substitutions`**: `id`, `group_name`, `date_str`, `pair_num`, `subject`, `room`, `teacher`, `custom_start`, `custom_end`. Если `subject` пустой — пара отменена.
4. **`consultations`**: `id`, `subject`, `room`, `day_num`, `time_start`, `time_end`.

**RLS:**
- Читать могут все авторизованные.
- Писать расписание/замены: `admin`, `sap`, `starosta` (только своя группа).
- Писать консультации и управлять пользователями: только `admin` и `sap`.

**Важно:** при запросах всегда используй `Number(weekNum)`, `Number(dayNum)`, `.trim()` для строк.

## 4. Логика

### 4.1. Время и даты
- Неделя: `(Math.floor(daysSinceStart / 7) % 2) + 1`, стартовая дата `2026-10-26`.
- День: 1-5 (в выходные 1).
- **Умный старт (`getSmartViewState`)**: Если сейчас выходной, возвращает `{ day: 1, offset: 1 }` (следующий понедельник). Если пятница после последней пары — тоже следующий понедельник. Иначе — текущий день.
- **Синхронизация календаря**: При инициализации страницы вызывается `updateHeaderAndCalendar()` сразу после отрисовки шапки, чтобы кастомный календарь сразу подсветил выбранный «умный» день.

### 4.2. Звонки и перемены
В `bells.js` каждая пара описана 4 точками: `start`, `breakStart`, `breakEnd`, `end`.

### 4.3. Умный таймер
- Учитывает текущий день и неделю.
- Если пары прошли → ищет следующую пару в `cache`.
- Кнопка «Ближайший» использует логику `getSmartViewState`.

### 4.4. Свайпы
- **Дни**: свайп влево/вправо переключает Пн-Пт по кругу.
- **Off-canvas меню**: свайп влево закрывает. Свайп игнорируется, если пользователь тащит ползунок (`input`).

### 4.5. Telegram Mini App
- В `offcanvas.ui.js` используется `history.pushState` и `popstate`, чтобы системная кнопка "Назад" корректно закрывала меню (или возвращала со страницы настроек).

### 4.6. Автоочистка замен
При заходе в админку `admin` или `sap` вызывается `cleanOldSubstitutions()`.

### 4.7. Версия сборки
В `vite.config.js` добавлен `define: { __BUILD_DATE__: ... }`.

### 4.8. Погода без VPN
В `weather.api.js` запросы идут через прокси `https://proxy.cors.dev/${url}`.

### 4.9. Анимация удержания (Жидкость)
Кнопки `.btn-hold-action` используют CSS-анимацию. Псевдоэлементы `::before` и `::after` служат слоями жидкости, которые поднимаются вверх с эффектом покачивания (`liquid-wobble`), а затем выравниваются.
- Для кнопки выхода: класс `.btn-hold-action` (время в JS — 3000мс, в CSS переменная `--hold-duration: 3s`).
- Для кнопок «Сбросить настройки» и «Удалить фон»: классы `.btn-hold-action .btn-hold-long` (время 3с). В CSS за это отвечает переменная `--hold-duration: 3s`.

### 4.10. Плавные переходы (SPA-эффект)
- В HTML-файлах прописан инлайн-стиль `html, body { background-color: #0f1115; }`, чтобы убрать белую вспышку при загрузке.
- В `src/ui/transitions.ui.js` создается элемент `.page-transition-curtain`.
- При клике на внутреннюю ссылку скрипт отменяет стандартный переход, показывает шторку с лоадером (через `classList`), и только потом меняет `window.location.href`.
- На новой странице при вызове `initTransitions()` шторка плавно исчезает.

### 4.11. Стили
- **ПК-версия**: `@media (min-width: 900px)`. Левая колонка `flex: 0 0 380px`, правая `flex: 1`.
- **Матовое стекло (Меню)**: Используется переменная `--menu-bg`. В Glass-теме это `rgba(20, 22, 26, 0.4)` + `backdrop-filter: blur(40px)`. В Classic — плотнее. Для кастомных цветов `--menu-bg` вычисляется в `settings.logic.js`.
- **Мобильный скролл**: `html, body` не должны иметь `overflow: hidden`.
- **Калькулятор**: Кастомная сетка 3x3.
- **Выходные в календаре**: В `custom-datepicker.ui.js` суббота и воскресенье получают класс `.disabled` и не имеют обработчика клика. В `custom-datepicker.css` для `.disabled` установлен `pointer-events: none` и `opacity: 0.3`.

### 4.12. Админка и парсинг данных
- Кастомные селекты (`createSearchableSelect`) возвращают **строки** (например, "2 неделя", "Понедельник").
- **Критически важно**: В `schedule.admin.js` и `substitution.admin.js` перед отправкой запроса в Supabase строки конвертируются в числа (через `includes('2')` или `map` объектов). Иначе Supabase выдаст ошибку `invalid input syntax for type integer: "NaN"`.
- В `admin-substitution.ui.js` добавлена проверка `is_changed`, чтобы не перезаписывать базу, если ничего не менялось.
- **Фикс текста в календаре**: При клике по дате в `custom-datepicker.ui.js` обновляется не только скрытый инпут, но и визуальный текст (`.date-text`), чтобы кнопка в админке замен показывала выбранную дату.

## 5. Что работает

1. ПК и мобильная верстка без багов скролла.
2. Умный выбор дня (суббота -> понедельник следующей недели) с мгновенной синхронизацией календаря в шапке.
3. Жидкая анимация кнопки выхода (синхронизирована с 3с).
4. Плавные SPA-переходы со шторкой и лоадером без белой вспышки.
5. Главная: свайпы, скелетоны, умный таймер (с фуллскрином), погода через `cors.dev`, стрик.
6. Админка: расписание, замены (с блокировкой выходных и синхронизацией текста даты), консультации, пользователи. Исправлен парсинг чисел из селектов.
7. Кастомизация: темы, цвета, частицы, обои, кастомный калькулятор, безопасный сброс настроек (3с).
8. Telegram Mini App: нативная кнопка "Назад".
